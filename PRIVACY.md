# Privacy notice

SeatAudit reads Jira account IDs, display names, account active state, account type, profile-visible email/avatar fields, inspectable projects, project roles, and role actors to create an administrator-requested audit. Hidden email is accepted as normal and is not treated as failure.

Processing occurs in Atlassian Forge and the customer browser. V1 has no ASHBIZCON service, telemetry, analytics SDK, advertising tracker, external AI, organization API-key collection, or external network egress. Forge KVS stores only schema-versioned policy, protection IDs/types, savings assumptions, default filters, and report preferences. Full inventories, emails, audit results, and exports are not persisted by SeatAudit.

CSV, HTML, and JSON reports are generated locally and downloaded only after an explicit administrator action. Those files may contain user data and are then governed by the customer's storage and handling controls. Jira/Forge platform processing remains subject to the customer's Atlassian agreements.
