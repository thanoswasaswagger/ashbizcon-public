# Support

ASHBIZCON provides partner support for SeatAudit for Jira.

## Contact

Email **support@ashbizcon.com** and include the SeatAudit version, Forge environment, non-sensitive diagnostic run ID, coverage states, and concise reproduction steps. Do **not** send exported user inventories, credentials, authorization headers, API tokens, or other secrets.

## Response target

- Initial response target: within 1 business day, Monday-Friday.
- Security reports: send to **security@ashbizcon.com** and do not include customer PII or credentials.
- Service-impacting defects are prioritized ahead of cosmetic issues and feature requests.

These are response targets rather than guaranteed resolution times. Resolution depends on reproducibility, Atlassian platform behavior, severity, and whether an upstream Atlassian fix is required.

## Supported scope

Support covers installation, permissions, live-audit failures, evidence interpretation, exports, settings, licensing behavior, and documented SeatAudit functionality. SeatAudit does not provide Atlassian account administration, identity-provider administration, tax/legal advice, or guarantees that a review candidate represents a removable paid seat.
