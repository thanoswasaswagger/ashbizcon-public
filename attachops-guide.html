AttachOps

Start with a small, reviewed workflow.

This guide describes the core workflow. Available features depend on your installed edition; review release notes before using a new capability.

  1. Open the installed app in Jira and scan an appropriate issue scope.
  2. Filter the inventory and select the attachments to review or download.
  3. Choose a ZIP folder layout and inspect part sizes. Large files may require separate parts.
  4. Read each ZIP manifest. Retry failed downloads only after reviewing the reason.
  5. For cleanup, review candidates and permission checks separately. Duplicate indicators alone are not deletion proof.

Need help?

Include the product name, visible error, affected feature and non-sensitive reproduction steps. Keep credentials, license keys, private content and order details out of public reports.
