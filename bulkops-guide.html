BulkOps

Start with a small, reviewed workflow.

This guide describes the core workflow. Available features depend on your installed edition; review release notes before using a new capability.

  1. Open the installed app in Confluence and choose a small page scope.
  2. Select the operation and targets. Query-wide selection is bounded; review the selected count.
  3. Run live preflight and inspect each page’s proposed action, current version and permission result.
  4. Confirm reviewed changes. Trash is recoverable; it is never a permanent purge.
  5. Review partial failures and operation history. Refresh changed pages before a new preview.

Need help?

Include the product name, visible error, affected feature and non-sensitive reproduction steps. Keep credentials, license keys, private content and order details out of public reports.
