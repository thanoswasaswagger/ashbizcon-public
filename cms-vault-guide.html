CMS Vault

Start with a small, reviewed workflow.

This guide describes the core workflow. Available features depend on your installed edition; review release notes before using a new capability.

  1. Open CMS Vault in the Framer project you want to inspect.
  2. Review the collection inventory and warnings, then save a JSON snapshot before making changes.
  3. Import a snapshot or validated CSV and inspect the comparison. Review unsupported fields and schema mismatches.
  4. Create a dry-run plan. Use a safe subset where the destination contains incompatible fields or protected data.
  5. After supported writes, review verification results and export the audit. Keep the original backup.

Need help?

Include the product name, visible error, affected feature and non-sensitive reproduction steps. Keep credentials, license keys, private content and order details out of public reports.
