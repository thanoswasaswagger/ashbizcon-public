SeatAudit

Start with a small, reviewed workflow.

This guide describes the core workflow. Available features depend on your installed edition; review release notes before using a new capability.

  1. Open the installed Jira app and run a live audit. Demo mode is labelled separately.
  2. Review coverage, account observations and project-role evidence.
  3. Inspect each candidate’s findings and limitations before selecting it for further review.
  4. Enter your own cost assumptions if a savings scenario is useful. The scenario is not guaranteed savings.
  5. Export the evidence and verify account access in your administration tools. SeatAudit does not deactivate accounts.

Need help?

Include the product name, visible error, affected feature and non-sensitive reproduction steps. Keep credentials, license keys, private content and order details out of public reports.
