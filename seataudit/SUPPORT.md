# SeatAudit for Jira — Support

ASHBIZCON provides partner support for SeatAudit for Jira.

## Contact

For product support, email **support@ashbizcon.com** or use the public ASHBIZCON work-item tracker.

Include the SeatAudit version, Forge environment, a non-sensitive diagnostic run ID if available, evidence coverage states, and concise reproduction steps. Do not send exported user inventories, credentials, authorization headers, API tokens, or other secrets.

For suspected security vulnerabilities, email **security@ashbizcon.com** privately. Do not post security vulnerabilities, customer PII, credentials, or tokens in the public tracker.

## Response target

- Initial response target: within 1 business day, Monday-Friday.
- Service-impacting defects are prioritized ahead of cosmetic issues and feature requests.
- Security reports are handled privately through the security contact.

These are response targets rather than guaranteed resolution times. Resolution depends on reproducibility, severity, Atlassian platform behavior, and whether an upstream Atlassian fix is required.

## Supported scope

Support covers installation, permissions, live-audit failures, evidence interpretation, exports, settings, Marketplace licensing behavior, and documented SeatAudit functionality.

SeatAudit does not provide Atlassian account administration, identity-provider administration, legal or tax advice, or a guarantee that a review candidate represents a removable paid seat.

## Public bugs and feature requests

Use the ASHBIZCON public GitHub Issues tracker for non-sensitive SeatAudit bugs and feature requests. Start the title with **[SeatAudit]** and include only information safe to make public.
