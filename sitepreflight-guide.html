SitePreflight

Start with a small, reviewed workflow.

This guide describes the core workflow. Available features depend on your installed edition; review release notes before using a new capability.

  1. Open SitePreflight in your Framer project.
  2. Select an inspection scope and review which checks can be evaluated.
  3. Inspect prioritized findings alongside their evidence and suggested next action.
  4. Correct the underlying issue in Framer and run the relevant checks again.
  5. Export the report for launch review. Check published behavior separately where the editor scan has no coverage.

Need help?

Include the product name, visible error, affected feature and non-sensitive reproduction steps. Keep credentials, license keys, private content and order details out of public reports.
