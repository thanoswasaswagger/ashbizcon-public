# ASHBIZCON SitePreflight — Support

Support for ASHBIZCON SitePreflight is provided through the public ASHBIZCON GitHub support channel:

https://github.com/thanoswasaswagger/ashbizcon-public/issues

When reporting a problem, include only non-confidential information such as:

- SitePreflight version;
- Framer version/build where available;
- operating system and runtime/browser context;
- whether the issue occurred during an all-pages or current-page scan;
- the rule/category involved;
- reproduction steps;
- the exact visible error text.

Do not include confidential customer project content, private URLs, credentials, tokens, or unsanitized exported audit reports.

## Scope

SitePreflight is a deterministic release-preflight utility. Support covers installation/use questions, reproducible product defects, report/export problems, and clarification of rule limitations. It does not provide general Framer consulting, custom site repair, or guarantees that every possible production issue can be detected.

## Security reports

For a suspected security issue, avoid posting sensitive exploit details or secrets in a public issue. Use the security guidance published in the ASHBIZCON public repository:

https://github.com/thanoswasaswagger/ashbizcon-public/blob/main/SECURITY.md
